5 — Touch targets + Forms

  • All buttons/nav items: min-height 44px (Apple HIG standard)
  • All input, select, textarea: font-size: 16px — prevents iOS auto-zoom on focus
  • Form rows that show side-by-side (label + input): stack vertically on mobile
  • Table row tap area extended — entire row is tappable where it opens a detail
  • Increased padding on nav items in drawer (easier to tap)

Summary of changes

  • Single @media (max-width: 768px) block added to <style>
  • ~10 lines JS for hamburger toggle (class on/off)
  • Hamburger ☰ button added to topbar HTML
  • Zero changes to desktop layout — fully additive
  • All existing CSS variables reused — same colors/fonts
