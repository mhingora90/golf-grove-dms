Mobile Navigation Pattern

The current sidebar is 220px fixed — it needs to change on mobile. Which pattern fits best?

Icon-only sidebar (36px) always visible

A — Slim Icon Sidebar

Sidebar collapses to 36px icons-only strip. Tap icon = navigate. No full-screen overlay. Desktop stays unchanged.

Pros

  • Always visible — no hidden nav
  • Familiar to desktop users

Cons

  • Icons alone need to be clear
  • Still eats 36px screen width

B — Hamburger Drawer

Topbar with ☰ button. Tap opens full sidebar sliding in from the left. Tap outside to close. Full screen used for content.

Pros

  • Full content width on mobile
  • Familiar pattern (most apps)

Cons

Bottom tab bar — group nav by section

C — Bottom Tab Bar

Sidebar gone on mobile. Bottom bar shows 4-5 section tabs (Main, Site, Finance, Sales, Admin). Tapping a tab shows sub-nav or goes straight to the section's first page.

Pros

  • Native-app feel on iOS/Android
  • Thumb-reachable navigation

Cons

  • Biggest departure from desktop
  • Sub-nav needs extra handling
